# הטאבון הנודד — Master Asset Prompt Book

כל prompt במסמך מיועד להרצה נפרדת. אין לבקש כמה תמונות, וריאציות, קולאז׳ או contact sheet באותה הרצה.

## כללי עבודה

- בכל prompt שמציג את אהרון, הגמל או הטאבון: לצרף את `public/brand/brand-primary-logo.png` כ־Image 1 ואת `assets/campaign-master/event-opener.png` כ־Image 2.
- בכל prompt של restoration: לצרף רק את קובץ היעד המקורי ולבקש שינוי מינימלי. אין לייצר את הלוגו מחדש.
- אין להטמיע עברית בתמונות חדשות. כותרות בעברית נשארות ב־HTML או מתווספות דטרמיניסטית לאחר ההפקה.
- צבעי המותג: `#F2E4C6`, `#D9B48A`, `#C56437`, `#FA6A1A`, `#2B2B2B`, `#7A5A3A`.
- בכל הרצה: Generate exactly one image.

# נכסים שלא כדאי לייצר ב־ImageGen

- `favicon.svg`: לגזור דטרמיניסטית מאייקון הלהבה או הטאבון המקורי.
- הטקסט העברי בכל הלוגואים: לשמר מהמקור; לא לבקש מהמודל לכתוב מחדש.
- קו האש, גיצים, grain, vignette ו־heat haze: עדיף Canvas/CSS כדי לשמור על תנועה, ביצועים ושליטה.
- `flame-ignition.json`: אנימציית Lottie קיימת; אם צריך שינוי, לערוך את קובץ האנימציה ולא להחליף אותו בתמונה סטטית.
- `file.svg`, `globe.svg`, `window.svg`: נכסי starter שאינם חלק מהמותג ואין צורך ליצור להם גרסאות חדשות.
- תמונות גלריה של אירועים אמיתיים: להשתמש בצילומים שהלקוח יספק; לא לייצר אנשים או אירועים פיקטיביים ולהציג אותם כתיעוד אמיתי.
